# my-oauth-apps

個人が自分だけで使うために作った OAuth クライアント（Google Cloud のアプリなど）のホームページです。
主に、Claude Code などのツールから MCP（Model Context Protocol）サーバーを使って、自分のアカウントのデータにアクセスするために使っています。

## アプリ一覧

| アプリ | 用途 | 使うAPI |
|---|---|---|
| Google カレンダー連携 | 自分の予定の確認・登録 | Google Calendar API |

## 利用者

これらのアプリは開発者本人だけが使います。一般公開や配布はしていません。
